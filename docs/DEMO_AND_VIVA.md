# Demo and viva guide

Explain the flow: TMDB DTO → repository/domain → StateFlow ViewModel → Compose. Room supports the local library/preferences. Recommendations use explicit weighted factors rather than an external AI service. Promotional videos and rights-reviewed complete films use separate eligibility paths. YouTube owns delivery and playback controls; the app cannot guarantee or bypass availability.

Demo route: Discover → Search → Details → add Favorite and Watchlist → Library → restart and verify persistence → Quiz → Recommendations/reasons → Genres → Compare two films → Details regional providers (India, then another region) → Details trailer → Free Movies feature. Perform the playback portions only after their device acceptance checks pass. Explain the architecture after showing these user flows.

The score is Genre(30) + Mood(20) + Era(15) + Quality(15) + Language(10) + Runtime(10), clamped to 0–100. Missing optional metadata uses neutral handling in the individual scoring functions. Candidates are deduplicated by movie ID; ties sort by audience rating, vote count, popularity and finally ascending ID. Match reasons come from the factors actually scored, not generated prose or a critic-rating service. Consult DeterministicRecommendationEngine for the exact thresholds rather than treating the percentage as a probability.
