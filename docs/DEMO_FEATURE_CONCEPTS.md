# MADVerse: Feature Demonstration Guide & MAD Concepts

This document provides a concise, accurate, and prioritized walkthrough of the MADVerse Android application for academic and project evaluation. It reflects the genuine state of the implementation running on the Samsung Galaxy A13.

---

## 1. Prioritized Demonstration Sequence

The demonstration follows a natural user journey:
**Discover $\rightarrow$ Search & Details $\rightarrow$ Trailer & Streaming $\rightarrow$ Library Persistence $\rightarrow$ Quiz & Recommendations $\rightarrow$ Genre Exploration $\rightarrow$ Comparison $\rightarrow$ Free Movies $\rightarrow$ Profile & Authentication.**

```
[1. Discover] ---> [2. Search & Details] ---> [3. Trailer & Streaming] ---> [4. Favorites & Watchlist]
                                                                                     |
[8. Free Movies] <--- [7. Comparison] <--- [6. Genre Explorer] <--- [5. Quiz & Recs] <----+
       |
       v
[9. Auth & Profile]
```

## 3. Demonstration Caveats & Live Rules

1. **Deterministic Scoring vs AI:** Never tell the evaluator that recommendations use Gemini or machine learning. The engine calculates an explicit weighted sum: Genre (30%), Mood (20%), Era (15%), Quality (15%), Language (10%), Runtime (10%).
2. **Third-Party Streaming Limitations:** Do not claim Netflix or Prime movies stream inside MADVerse. Streaming badges display availability information and provide JustWatch attribution links to external platforms.
3. **Catalogue Classification:** State accurately that the Free Movies catalogue contains **one full-length feature film** (*Star Wreck: In the Pirkinning*, ~103 min) and **three animated/VFX open-source short films** (*Big Buck Bunny*, *Sintel*, *Tears of Steel*).
4. **Offline Capability Boundary:** MADVerse is an offline-capable hybrid. Room stores user favorites, watchlist entries, and quiz preferences locally without network access. Discovery feeds, search results, trailer streaming, and details require an active internet connection.
5. **Runtime Playback Testing:** Verification on device confirms that player initialization, video decoding, and playback controls work reliably. It does not imply that full 103-minute videos were played unattended from start to finish during automated testing.
